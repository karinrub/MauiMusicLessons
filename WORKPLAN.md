Maui Music Lessons Website

Detailed Refinement Work Plan

Project Goal

Improve the existing website without changing its core identity.

Preserve:

* overall visual direction
* photography
* editorial typography
* section structure
* dark luxury aesthetic
* cinematic feeling
* current storytelling approach

Do not redesign the website.

Do not replace the visual language.

Do not create a new aesthetic direction.

The goal is to transform the current version into a more polished, cohesive, readable, and professional version of itself.

⸻

Phase 1 — Global Systems Review

Before modifying any individual section, review the systems that affect the entire website.

Overlay System

Audit every image overlay, video overlay, gradient overlay, and darkening layer.

Current issue:

Different sections use dramatically different darkness levels.

Some images retain detail and atmosphere.

Others become almost black.

This creates inconsistency and reduces the impact of the photography.

Goals:

* improve image visibility
* improve text readability
* preserve cinematic atmosphere
* create visual consistency between sections

⸻

Vertical Rhythm

Review spacing throughout the entire experience.

Current issue:

Many sections feel disconnected because of excessive vertical spacing.

The user frequently scrolls through areas where little or nothing happens.

Goals:

* remove dead space
* tighten transitions
* improve momentum
* maintain breathing room without creating emptiness

⸻

Motion System

Review every animation.

Evaluate:

* reveal timing
* opacity transitions
* scroll-triggered animations
* text appearance timing
* image appearance timing

Current issue:

Important content often appears too late.

Animations occasionally delay readability.

Goals:

* improve responsiveness
* make content visible sooner
* create consistency throughout the experience

⸻

Phase 2 — Hero Section

Current Strengths

This is currently the strongest section on the website.

The photography immediately communicates Maui.

The headline is clear.

The booking CTA is obvious.

The atmosphere feels authentic.

The section successfully establishes the brand.

Review Areas

Navigation

Evaluate:

* readability over the image
* contrast
* visibility while scrolling
* transition from transparent to solid state

Current issue:

The navigation occasionally feels disconnected from the hero and can become difficult to read depending on image brightness.

Typography

Review:

* headline positioning
* line breaks
* supporting text width
* spacing between elements

Current issue:

The supporting copy feels slightly crowded beneath the headline.

CTA Hierarchy

Review:

* button prominence
* relationship between primary and secondary actions

The CTA works well and should not be redesigned.

Only refine spacing and emphasis.
